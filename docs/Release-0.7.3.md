# AeroTrace 1553 0.7.3 bench candidate

Version 0.7.3 packages the current capture and ICD workspace with the refreshed
operator shell. Monitor & Record and Live Plot Analysis prioritize larger viewing
surfaces; CSV Viewer is separate from Exports & Reports; and Device Setup is
combined with Recording Setup for a more compact workspace.

Bus Analysis, the in-app ICD Assistant, and License & Security are retired from
the operator-visible shell for this release. Startup retains the five-second
minimum splash/loading check, and the layout remains responsive at the supported
100% and 150% Windows display scales.

Native, provider, helper, packaged UI, and installer results are recorded in the
accompanying installer receipt. Physical DDC, installation/upgrade,
silent/cancellation, and visual installer-animation acceptance remain separate
pending gates.
