# AeroTrace Phase Two

The **ICD Library** has actions on the attached PDF, subsystem, and mapping
table. Right-click a row or use its visible action control. Permanent deletion
shows the affected scope, then asks you to type DELETE. The app retains saved
recordings and chat history. Shared PDF copies remain available to other
revisions. Pending deletions resume at startup and can be retried from Manage ICDs.

**Manual mappings** opens the command list and guided editor. Add or edit a
command, then add each field with its raw example. Select the commands to
activate and publish once their examples pass. For custom conversion, x is
the decoded field value. Supported syntax includes finite constants,
parentheses, +, -, *, /, abs, sqrt, min, max, and pow. Custom fields need two
distinct passing raw examples. The version 3 profile schema carries the
expression. Finish recording before changing the active profile.

**Focus view** enlarges the current bus table or live plot. From the focused
monitor, **Plots** opens large plot rows. **Bus records** returns to the monitor.
The sidebar has direct destinations and can collapse to icons.

In **AeroTrace Assistant**, choose a PDF revision and ask a question.
**Cited lookup** is included with the base package. **Local RAG** uses the
optional local model. Choose **Local model pack…** and select its
assistant-runtime directory. The runtime verifies its pinned assets before use.
Use **Sources** to inspect the evidence, including OCR-derived text.
Ask "Convert Temperature from raw 0064" to verify a published field in the
selected revision with the native decoder. PDF evidence can be saved as a
draft for review. Use Manual mappings to publish verified conversions.

The synthetic Thermal Bench example includes an answer key, a conflicting
earlier revision, and a scan. Use it for validation without connecting hardware.
